User Guide

How to use the Publisher Transfer Tool

Back to App

Welcome

The Publisher Transfer Tool helps you take a full congregation export from Hourglass and pull out just the publisher(s) you need — producing a clean JSON file that can be imported into New World Scheduler (or a similar program) at the receiving congregation. It can also generate a printable Letter of Introduction PDF for each publisher.

1. Your privacy — how your data is handled

Everything happens on your own computer, inside your browser. The publisher information in your file — names, addresses, phone numbers, dates, field service reports — is never uploaded or sent anywhere. Nothing is stored on a server.

When you upload a file, it is read and processed locally. When you download a transfer file or a letter PDF, it is created right there in your browser. If you close or refresh the page, all the loaded data is cleared. Because of this, you can use the tool with confidence that congregation information stays private.

2. Getting your export file from Hourglass

Before using this tool you need the full congregation data exported from Hourglass as a JSON file. In Hourglass, use the data export option to download your congregation data in JSON format and save it somewhere you can find it (for example, your Downloads folder).

Note: The file you download from Hourglass contains every publisher in your congregation. That is expected — this tool is what narrows it down to only the person (or people) you want to transfer.

1

Step 1 — Upload the file

On the main page you'll see an Upload Hourglass Export box with a dashed drop area.

  • • Drag and drop your JSON file onto the dashed box, or
  • • Click the box (“or click to browse”) to open a file picker, then choose your JSON file.

As soon as a valid file is loaded, the tool moves you to Step 2 automatically. If you pick the wrong kind of file, a red message appears explaining the problem — just choose the correct .json file and try again.

2

Step 2 — Select publishers

This screen lists every publisher in the file. A blue bar at the top confirms which congregation was loaded and how many publishers and reports it contains.

Finding the right person

  • • Search box: Start typing a name. It matches first name, last name, or both (for example, typing joe gills finds “Gills, Joe”).
  • • Status filter: The dropdown next to the search box lets you show only a certain type (for example, only Regular Pioneers).
  • • Sort: Click the Name, Status, or Appointment column headings to sort the list. Click the same heading again to reverse the order (the small arrow shows the direction).

Choosing who to transfer

  • • Click a row (or its checkbox) to select that publisher. Click again to unselect. You can select one person or several (handy for a family transferring together).
  • • Select all visible: The checkbox above the list selects everyone currently shown (respecting any search or filter you have applied).
  • • The Reports column shows how many field service reports each publisher has — these travel with them in the transfer.

The counter shows how many are selected. When at least one person is selected, the Generate Export → button becomes active. Click it to continue. (Use ← Back to return to the upload screen if you loaded the wrong file.)

3

Step 3 — Download the transfer file

The export screen summarizes what you're about to create: the number of publishers and their reports, with each selected name listed.

  • • Download JSON File: Creates the transfer file containing only your selected publisher(s), their address and contact details, and their field service reports — formatted so New World Scheduler can import it. The file is named for the publisher and date, e.g. Transfer_Gills_Joe_2026-07-29.json.
  • • ← Back to Selection: Return to the list to change who is selected.
  • • Start over with a new file: Clears everything so you can load a different export.

Send the downloaded JSON file to the receiving congregation (see section 7 for how they import it).

6. Letters of Introduction

Below the download button on Step 3 is the Letters of Introduction section. It creates a ready-to-print PDF letter for each selected publisher, with the wording filled in based on your choices.

Letterhead (top of the section)

  • • Sending Congregation and Congregation Address are pre-filled from your file and appear at the top of every letter. Edit them if needed — changes apply to all letters.

Each publisher's card

Every selected publisher gets a card. As you change the options, the letter text below regenerates automatically. The choices work like the columns of a form — picking an option drops the matching sentence into the letter:

  • • Transferring to: Type the name of the congregation they are moving to.
  • • Standing in the ministry: Choose Exemplary, In good standing, Irregular (needs encouragement), or Inactive (needs shepherding). Irregular and Inactive replace the recommendation with appropriate, kindly worded shepherding language.
  • • Publisher status: Regular Pioneer, Auxiliary Pioneer, Baptized Publisher, Unbaptized Publisher, etc. Pre-filled from the file; change it if it's out of date.
  • • Appointment / servant role: None, Elder, or Ministerial Servant. Combined with the status to produce the correct “serving as… recommended to continue as…” sentence.
  • • Comments at meetings & participates in CLM student assignments: Check this to add that sentence. It's on by default; uncheck it for someone who doesn't share in the CLM, even if they're otherwise exemplary.
  • • Approved public speaker and Circuit / regional teaching assignments (shown for brothers): Check these to add the corresponding paragraph about public speaking privileges.
  • • Additional notes: Anything you type here is added as its own paragraph — use it for personal circumstances, history with the congregation, or specific shepherding suggestions.

The letter text box

The generated letter appears in an editable text box. You can fine-tune any wording by typing directly in it. If you change the options above after editing, click Regenerate to rebuild the letter from the current selections (note: this replaces your manual edits).

Download Letter PDF

Click Download Letter PDF to save a formatted letter with your congregation letterhead, today's date, the body text, and the publisher's details (birth date, baptism date, pioneer ID if any, and contact information). Each publisher gets their own letter.

Always review before sending. The wording is a helpful starting point generated from your selections. Read each letter and adjust it so it accurately reflects the individual before you print or send it.

7. Importing into New World Scheduler

The receiving congregation opens New World Scheduler and uses its Import from Hourglass option, then selects the JSON file you sent. The file is built to match the format that importer expects, so the publisher, their details, and their field service reports come through together.

8. Troubleshooting & FAQ

The upload says my file is invalid.

Make sure you're choosing the JSON file exported from Hourglass (its name ends in .json) and that it hasn't been edited or renamed to a different type.

Can I transfer more than one publisher at once?

Yes. Select as many as you like in Step 2. The transfer file and a separate letter will be produced for the whole group.

A publisher's status or appointment is wrong in the letter.

The dropdowns on each letter card are pre-filled from the file but fully editable. Change them and the letter updates instantly.

My manual edits to a letter disappeared.

Changing any option on the card (or clicking Regenerate) rebuilds the letter and replaces manual edits. Make your dropdown/checkbox choices first, then do any hand-editing last.

Is my congregation's data safe?

Yes — see section 1. Nothing you load is ever sent off your computer.

The import into New World Scheduler failed.

Make sure the receiving congregation is using the Import from Hourglass option and selecting the exact JSON file you sent (not a renamed or modified copy). If it still fails, re-download a fresh file from this tool and try again.
